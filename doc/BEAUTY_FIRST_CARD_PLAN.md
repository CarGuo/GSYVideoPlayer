# 美颜（保边磨皮 + 暖色美白）首张卡片实施计划

## 1. 背景

播放 / 直播场景对“美颜”是刚需。现有 `GaussianBlurEffect` 是普通二维模糊，
会把五官轮廓、眼睛、头发一起糊掉，无法用于人脸；且此前复核发现它并非
真·可分离模糊。美颜需要的是**保边平滑**：抹掉雀斑、痘印、传感器噪点等低对比
细节，但保留眼、眉、唇、人脸轮廓等高对比边缘；再叠一个**暖色美白**曲线。

## 2. 目标

1. 新增单 pass `BeautyEffect`：双边滤波（bilateral）单 pass 近似的保边磨皮。
2. 叠加暖色美白（中间调提亮 + 轻微暖肤色偏移），强度可调。
3. 接入 demo，播放中设备验证：皮肤平滑、边缘清晰、不过度磨皮 / 不假白。

## 3. 非目标

- 不做人脸关键点检测 / 分区（腮红、大眼、瘦脸），只做整体像素级磨皮 + 美白。
- 不做多 pass 高成本双边 / 引导滤波（实时性优先，用固定小核近似）。
- 不做参数滑杆 UI（构造传参，demo 给几档预设）。

## 4. 技术方案

### 4.1 双边滤波单 pass 近似（保边原理）

普通模糊每个邻居只按**空间距离**加权，所以边缘也被平均。双边滤波再乘一个
**颜色（亮度）差权重**：

```
W(p, q) = W_space(|p-q|) * W_color(|luma(q) - luma(p)|)
```

- 平坦皮肤 / 雀斑：邻居亮度差小 → W_color≈1 → 被平滑；
- 五官轮廓两侧：亮度差大 → W_color≈0 → 不采纳对面像素 → 边缘保留。

为控制 ES 2.0 单 pass 成本，采用 **8 方向 × 2 环 = 16 邻居 + 中心**的固定小核：

- 方向为 8 个均匀角度，环半径取 `r`、`2r`（纹元，纹元 = `1 / uViewSize`，
  复用渲染器已每帧绑定的 `uViewSize`，不新增 uniform）；
- 空间权重按环距离固定（近大远小）；
- 颜色权重 `exp(- (lumaN - lumaC)^2 / (2 * sigmaC^2))`；
- 循环边界为编译期常量（ES 2.0 要求），方向 / 空间权重以常量数组内联。

参数：

- `smoothLevel`（0~1）→ 映射磨皮半径 r（约 1.5~5 px）与颜色域 sigmaC
  （越大越多邻居被纳入，磨得越狠）；smoothLevel=0 时退化为原图，不做采样平均。

### 4.2 暖色美白

在磨皮结果上（`whiteLevel` 0~1）：

1. **提亮**：非线性提亮中间调、保护高光，近似
   `c' = 1 - (1-c)^2` 形态的曲线按 whiteLevel 混合（避免高光一刀切过曝）；
2. **暖肤色偏移**：提亮的同时 R 通道增益略大于 B，叠加极轻微暖色调，使肤色
   白皙通透而非惨白；
3. 保持 alpha 不变。

### 4.3 构造与接入

```java
new BeautyEffect(float smoothLevel, float whiteLevel)
```

demo 滤镜序列中新增“美颜（自然 / 强力）”档位，沿用单 pass 渲染链路
（samplerExternalOES → 直接处理 OES），无需 FBO / 纹理资产。

## 5. 影响面

- 新增：`BeautyEffect`（render/effect）。
- 修改：demo 滤镜页加入美颜档位。
- 不改渲染器、不影响既有 27 滤镜与多 pass / 金字塔 / Bloom / LUT。

## 6. 风险与对策

- 磨皮过度 / 塑料感：默认用自然档，限制最大半径与 sigmaC；强力档单列。
- 边缘仍被糊：颜色域权重以亮度差为准，并验证高对比边缘两侧不串色。
- 16 tap + exp 性能：固定小核、常量循环可被编译器展开；若设备掉帧再减为
  8 邻居或用更便宜的权重近似。
- 美白发灰 / 假白：提亮曲线保护高光 + 暖色偏移，按 whiteLevel 与原图 mix。

## 7. 测试与验收

1. 构建 `:app:assembleDebug` 并安装。
2. **播放中**采帧（暂停 / 结束态 GL 不重绘，须在播放窗口内截图）：
   - 皮肤区域比 NoEffect 平滑（雀斑 / 噪点减弱）；
   - 五官、人脸 / 主体轮廓、头发边缘清晰，无整体糊化；
   - 美白档肤色更亮且偏暖，高光不过曝、不假白。
3. smoothLevel=0 / whiteLevel=0 时分别对应“只美白不磨皮 / 只磨皮不美白”。
4. logcat 无 FATAL、无 shader 编译 / 链接错误。
5. 回归：既有滤镜与其它渲染场景不受影响。
