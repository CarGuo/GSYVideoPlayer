# 老电视信号干扰（Old TV Signal / Bad Reception）首张卡片实施计划

## 1. 背景

已打通 `uTime` 时间维度并落地两类动态效果，但其定位各有侧重：

- `GlitchEffect`：**数字**信号故障——量化时间跳变、RGB 错位、数字丢块、噪点；
- `CrtEffect`：显像管**硬件物理**特性——屏幕弯曲、扫描线、RGB 像素栅格、暗角。

短视频 / 复古题材还高频需要另一种观感：**模拟天线接收不良**（bad reception）——
满屏翻滚的密集雪花、垂直滚动的横向干扰带、水平失步（hold 不稳）、多径重影
（鬼影）、以及间歇性"丢台"瞬间整屏全雪花。这是一种**连续的、模拟的、带有
信号强度起伏**的效果，与数字故障的"硬跳变"和 CRT 的"固定栅格"都不同。
本卡新增 `OldTvSignalEffect`，复用现有 `uTime` / `uViewSize`，单 pass 实现。

## 2. 目标

1. 新增单 pass `OldTvSignalEffect`，构造参数 `strength`（0~1）。
2. 包含以下模拟信号特征，且随 `uTime` 连续变化：
   1. **密集雪花噪点**：每帧、每像素滚动的黑白颗粒（高帧率连续随机，非量化）；
   2. **垂直滚动干扰带**：一条缓慢向下滚动的横向亮 / 暗带 + 细滚动条；
   3. **水平失步**：画面整体随时间做小幅非线性 x 漂移（V-hold 不稳）；
   4. **多径重影**：采样 1~2 个 x 方向偏移副本，弱叠加成鬼影；
   5. **间歇丢台**：按时间周期出现的短暂"无信号"段，整屏全雪花；
   6. **旧电视调色**：轻微降饱和、对比抬升、偏暖黄，叠少量扫描线与暗角。
3. 接入 demo（默认渲染场景滤镜序列追加"老电视干扰"）。
4. 播放中设备验证：多帧截图可观察到滚动带位置、雪花、丢台段的差异；无 GL 报错。

## 3. 非目标

- 不做音频驱动 / 视频 PTS 对齐，仅用墙上时钟 `uTime`。
- 不做多 pass（单 pass 多次采样即可，实时性优先）。
- 不做参数滑杆 UI（构造传强，demo 固定预设）。
- 不复刻 CRT 的屏幕弯曲与三色像素栅格（那是 `CrtEffect` 职责，本卡只借扫描线/暗角点到为止）。
- 不做数字丢块 / 硬量化跳变（那是 `GlitchEffect` 职责）。

## 4. 技术方案

### 4.1 随时间滚动的连续随机

- 雪花需要"每帧都在翻滚"，因此随机种子直接乘一个较大的时间系数
  （如 `floor(uTime*24.0)`），而非 `GlitchEffect` 的 `*8.0` 慢跳变；
  在同一帧内对每个像素稳定，跨帧快速变化，形成滚动雪花。
- hash：`fract(sin(dot(p, vec2(127.1,311.7))) * 43758.5453)`，与现有效果一致，
  避免引入额外函数风格。

### 4.2 信号强度与丢台

- `signal`：用周期函数 + hash 产生缓慢起伏的"接收质量"，正常段接近 1。
- `drop`：以较长周期（约若干秒）在很小的时间窗内判为"丢台"，丢台时
  `signal→0`，画面几乎只显示雪花；丢台段做短暂淡入淡出，避免硬切。
- 所有时序随机量按"秒量化"，保证同一丢台段在一帧内判定一致。

### 4.3 几何与采样

1. 失步漂移：`uv.x += drift`，`drift` 由低频 `sin(uTime)` + 少量 hash 抖动构成；
2. 重影：在漂移后的 uv 上额外采样 `uv ± ghostOffset`，以小权重叠加；
3. 主采样保留 alpha；雪花与干扰带只作用于 rgb。

### 4.4 调色与叠加（按强度混合）

- 降饱和（朝亮度收敛）+ 轻微对比 + 暖黄偏移，强度由 `strength` 控制；
- 垂直滚动带：`band = sin((uv.y - uTime*speed)*2π)`，加一条更细的滚动亮条；
- 少量水平扫描线与暗角，弱化处理以区别于 `CrtEffect`；
- 最终 `mix(原图风格, 雪花/干扰, 由 signal 与 strength 决定的比例)`，并 clamp。

### 4.5 接入

- `DetailFilterActivity`：`FILTER_EFFECT_NAMES` 追加"老电视干扰"，
  `resolveTypeUI()` 追加对应 `case`（`new OldTvSignalEffect(0.9f)`）。
- 复用现有切换逻辑，无需改动渲染器（`uTime`/`uViewSize` 已具备）。

## 5. 测试与验收

2. 模拟器播放中切到"老电视干扰"：
   - 连续两帧 / 多帧截图，能看到雪花翻滚、滚动带位置变化；
   - 若采到丢台段，可见整屏接近全雪花；否则间隔等待补采。
   存 `app/test_evidence/oldtv-card/`。
3. logcat 无 GL 编译 / 链接错误。
